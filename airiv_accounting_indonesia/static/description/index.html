AIRIV Indonesia SAK EMKM Accounting

Indonesia SAK EMKM Accounting & Financial Reports

Community-ready Indonesian accounting report layer for Odoo 18 with SAK EMKM account classification, Laba Rugi, Neraca, report line calculation, and PPh Final UMKM 0.5% tax fixture.

Odoo 18 CommunitySAK EMKMLaba RugiNeracaAIRIV

Core Capabilities

AIRIV Accounting Indonesia adds a practical SAK EMKM reporting workspace to Odoo Community using native account moves, account categories, and calculated financial report records.

SAK EMKM Mapping

Account classification

Add Indonesian SAK EMKM category fields to chart of accounts for assets, liabilities, equity, revenue, HPP, operating expense, and other income/expense.

Financial Reports

Laba Rugi and Neraca

Generate report lines from posted account move lines for income statement and balance sheet summaries.

Tax Fixture

PPh Final UMKM 0.5%

Install a PP 55/2022 PPh Final UMKM 0.5% sales tax fixture for Indonesian MSME accounting scenarios.

Feature & Workflow Automation

1

Prepare accounts

Review chart of accounts and fill SAK EMKM category mapping where needed.

2

Post accounting entries

Use standard Odoo accounting documents so posted move lines become the report source.

3

Calculate report

Create Laba Rugi or Neraca report records, choose date range and company, then calculate report lines.

4

Review totals

Check revenue, HPP, operating expenses, net income, assets, liabilities, equity, and balance difference.

Installation Guidance

Install

Add to Odoo addons

Clone branch 18.0, add the module folder to your addons path, restart Odoo, update the apps list, and install the module.

Configure

Map accounts

Review Odoo accounts and set SAK EMKM categories for Indonesian reporting clarity.

Operate

Calculate reports

Create a financial report, select report type, company and period, then run the calculation action.

Configuration Checklist
